# Coffee Shop Sales Dashboard (Excel)

An interactive Excel dashboard designed to analyze and visualize coffee shop sales data, highlighting key trends and performance metrics.

## 📊 About the Project
This project provides a comprehensive, data-driven view of a coffee shop's performance. Built entirely in Microsoft Excel, the dashboard transforms raw transaction data into actionable insights. It is designed to help business owners or analysts easily track revenue, understand peak busy hours, and identify top-selling products.

## 🚀 Key Features
* **Revenue Tracking:** High-level overview of total sales, total orders, and average order value.
* **Time-Based Trends:** Visualizations showing sales by day of the week, month, and hour to identify peak times.
* **Product Performance:** Breakdown of top-selling items (e.g., specific coffee drinks, pastries) by volume and revenue.
* **Interactive Filters:** Built-in Excel slicers to easily filter the dashboard by date, product category, or specific locations.



## 📁 Dataset
The analysis is based on transactional coffee shop data, which includes:
* Transaction Date & Time
* Product Category & Specific Item Name
* Quantity Sold
* Unit Price & Total Revenue
